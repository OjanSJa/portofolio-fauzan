Dasar-Dasar Web Development: Frontend dan Backend

Ditulis oleh Muh. Fauzan Arrizal Sadewa · Catatan Belajar

Sebelum terjun lebih jauh membangun proyek website, penting bagi saya untuk memahami konsep dasar dari pengembangan web itu sendiri. Secara umum, web development terbagi menjadi dua sisi besar yang saling melengkapi, yaitu frontend dan backend. Keduanya bekerja sama membentuk sebuah aplikasi web yang utuh, mulai dari tampilan yang dilihat pengguna hingga proses di baliknya yang tidak terlihat.

Apa Itu Frontend?

Frontend adalah bagian dari website yang langsung berinteraksi dengan pengguna, atau biasa disebut client-side. Semua yang tampil di layar browser seperti tata letak, warna, tombol, formulir, dan animasi merupakan hasil kerja dari frontend. Tiga teknologi dasar yang menjadi fondasi frontend adalah:

  • HTML (HyperText Markup Language) — digunakan untuk menyusun struktur dan konten halaman, seperti judul, paragraf, gambar, dan tabel.
  • CSS (Cascading Style Sheets) — digunakan untuk mengatur tampilan visual, mulai dari warna, jarak antar elemen, hingga membuat tampilan responsif di berbagai ukuran layar.
  • JavaScript — digunakan untuk menambahkan interaktivitas, seperti validasi formulir, animasi, hingga mengambil data dari server tanpa perlu memuat ulang halaman.

Selain teknologi dasar tersebut, saat ini banyak pengembang frontend juga menggunakan framework atau library seperti React, Vue, atau Bootstrap untuk mempercepat proses pembangunan tampilan yang rapi dan konsisten.

Apa Itu Backend?

Berbeda dengan frontend, backend adalah bagian yang bekerja di sisi server atau biasa disebut server-side, dan tidak terlihat langsung oleh pengguna. Backend bertugas mengolah logika bisnis, mengelola data, serta memastikan permintaan dari frontend diproses dan dijawab dengan benar. Beberapa komponen penting dalam backend antara lain:

  • Bahasa pemrograman server, seperti JavaScript (Node.js), PHP, Python, atau Java, yang digunakan untuk menulis logika aplikasi.
  • Database, seperti MySQL atau MongoDB, yang digunakan untuk menyimpan dan mengelola data secara terstruktur.
  • API (Application Programming Interface), yang menjadi jembatan komunikasi antara frontend dan backend, biasanya dalam bentuk REST API yang mengirim dan menerima data dalam format JSON.

Saat mengerjakan proyek toko rajut untuk Uji Serkom, saya menggunakan Node.js dengan Express sebagai backend, ditambah MySQL sebagai database, untuk mengelola data produk, kategori, hingga pesanan pelanggan.

Bagaimana Frontend dan Backend Saling Terhubung

Alur kerja sederhananya dimulai ketika pengguna membuka website melalui browser. Frontend akan menampilkan halaman dan menerima interaksi dari pengguna, misalnya saat mengisi formulir atau menekan tombol "Beli". Data tersebut kemudian dikirim ke backend melalui permintaan HTTP. Backend akan memproses permintaan itu, misalnya menyimpan data ke database atau mengambil data produk, lalu mengirimkan hasilnya kembali ke frontend untuk ditampilkan kepada pengguna. Proses bolak-balik inilah yang membuat sebuah website terasa "hidup" dan interaktif.

Kesimpulan

Memahami dasar-dasar frontend dan backend menjadi bekal penting sebelum membangun aplikasi web yang lebih kompleks. Frontend berfokus pada bagaimana sebuah website terlihat dan terasa oleh pengguna, sementara backend berfokus pada bagaimana data diolah dan dikelola di balik layar. Dengan memahami peran keduanya, saya jadi lebih mudah menentukan teknologi yang tepat serta memahami alur kerja aplikasi secara menyeluruh, sebagai bekal menuju profesi Junior Web Developer.
