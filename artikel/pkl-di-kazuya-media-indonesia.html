PKL di Kazuya Media Indonesia

Ditulis oleh Muh. Fauzan Arrizal Sadewa · Praktik Kerja Lapangan

Selama menjalani Praktik Kerja Lapangan (PKL) di Kazuya Media Indonesia, saya mendapat banyak sekali pengalaman baru yang tidak saya dapatkan di bangku sekolah. Salah satu hal paling berkesan adalah kesempatan belajar langsung membangun aplikasi web menggunakan framework Laravel, bekerja dengan database yang sesungguhnya, dan mengenal pola arsitektur MVVM (Model-View-ViewModel).

Belajar Laravel

Sebelum PKL, saya hanya terbiasa membangun website dengan HTML, CSS, dan JavaScript polos, atau paling jauh menggunakan Node.js dan Express. Di Kazuya Media Indonesia, saya diperkenalkan dengan Laravel — sebuah framework PHP yang sangat populer untuk membangun aplikasi web dengan cepat dan rapi. Saya belajar bagaimana Laravel mengatur routing, controller, dan view secara terstruktur, sehingga kode menjadi lebih mudah dibaca dan dikelola dibanding menulis PHP murni.

Bekerja dengan Database

Selain belajar Laravel, saya juga banyak berlatih merancang dan mengelola database untuk aplikasi yang sedang dikerjakan. Saya belajar cara membuat tabel, relasi antar tabel, hingga menulis query untuk mengambil dan mengolah data. Pengalaman ini sangat membantu saya memahami betapa pentingnya struktur database yang baik agar aplikasi bisa berjalan efisien dan datanya tetap konsisten.

Mengenal Pola MVVM

Hal lain yang cukup baru bagi saya adalah pola arsitektur MVVM. Berbeda dengan MVC yang lebih umum saya dengar sebelumnya, MVVM memisahkan logika tampilan (View) dengan logika data (Model) melalui sebuah penghubung yang disebut ViewModel. Pola ini membuat kode menjadi lebih terorganisir, terutama ketika aplikasi mulai berkembang dan fiturnya semakin banyak.

Kesimpulan

Pengalaman PKL di Kazuya Media Indonesia benar-benar membuka wawasan saya tentang bagaimana proses pengembangan aplikasi web dikerjakan secara profesional di dunia kerja nyata. Dari yang awalnya hanya bisa membuat halaman web sederhana, saya jadi mengerti bagaimana sebuah aplikasi dibangun dengan struktur yang rapi, menggunakan framework, database, dan pola arsitektur yang jelas. Pengalaman ini menjadi bekal berharga untuk perjalanan saya selanjutnya sebagai calon Junior Web Developer.
